# SAMMY MEDIA KE

A modern media company website for wedding, event, brand, and digital storytelling.

## Local preview

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This project is a static website and is ready for deployment to:
- GitHub Pages
- Netlify
- Vercel
- any static hosting provider

If using GitHub Pages, push this repo to GitHub and enable Pages from the repository settings.
